iPhone Duo

Ready for the foldable

Token Ledger is built with the iOS 27.1 SDK, so it is optimised for iPhone Duo out of the box: the app uses the whole display, and the system moves the tab bar and the toolbar items down the side. None of the dashboard is sized to a named device, so it adapts to whatever window it is given.

  • Both displays, one continuous app. Open it and the app fills the inner display; close it and it returns to the outer one, with your place kept.
  • Two columns when there is room. A wide, landscape-shaped window pairs the balance and charts with the account log; anything narrower keeps the familiar single column.
  • Nothing under the hinge. On a partly folded Duo the content is pushed clear of the folding region instead of being laid across it.
  • Vertical bars handled. Refresh and Done are pinned, so they stay reachable when the navigation bars are presented down the side of the display.

Also works in iPad split view, Stage Manager and iPhone Mirroring. iPhone and iPad, iOS 27.0 or later.

Features

Everything the API doesn't tell you

openrouter.ai gives you a bill. Token Ledger shows you where the money went, which tool spent it, and what each call really cost.

Balance & spending

Remaining credit (or your key limit), lifetime and monthly spend, plus a low-balance banner that turns amber below $10 and red below $5.

Usage charts

Daily spend and token bars with a period average, a least-squares trend line, and tap-a-day detail down to the prompt / completion / reasoning split.

Account log

OpenRouter bills per API key — so give every tool its own key (Hermes, Agent-Zero, a coding CLI…) and the log becomes a per-app view: today / 7-day / month / lifetime spend, key limits, expiry and each key's own daily history and model list.

This is the feature people didn't know they needed.

Model catalog

All 400+ models with real per-1M-token prices, capability filters (Vision · Developer · Reasoning · Free), search and server-side sorting.

Two providers

OpenRouter, TrustedRouter, or both — remaining credit, prepaid-vs-BYOK split, per-key limits and a provider switcher that keeps every account separate.

Privacy first

Keys live only in the iOS Keychain. Optional PIN (salted SHA-256) and Face ID, re-lock when the app backgrounds, and an optional app-switcher blur.

Stay informed

Low-balance notifications on each crossing, a Sunday-evening weekly summary, and a home- & lock-screen widget in Balance or Today's-usage mode.

Siri & Shortcuts

Ask “What's my OpenRouter balance?” or “What's my usage today?” without opening the app.

Export

Share any period as CSV (daily rows + per-model rows) or as a print-ready PDF report.

Privacy

Nothing leaves your device except queries to your own provider

Token Ledger has no accounts, no analytics SDK, no advertising and no third-party tracking. It talks to exactly two hosts — and only if you connect them.

Keys in the Keychain

Provider keys are stored on-device, encrypted, with device-only accessibility. Never in preferences, never on a server.

Two destinations only

openrouter.ai and trustedrouter.com, over HTTPS, using your own keys. No other party receives anything.

No tracking, ever

No analytics, no crash reporting, no ads. The optional review prompt only counts launches on your own device.

Delete anytime

“Remove all data” wipes keys and protection immediately. Uninstalling removes everything else.

FAQ

Questions

Which keys does the app need?

OpenRouter: a standard API key (openrouter.ai/keys) for the model catalog and key info, and a management key (openrouter.ai/settings/api-keys) for the credit balance and usage charts.

TrustedRouter: one API key from their console covers the balance, today/week/month spend and key limits. Per-day history and total credits additionally need a TrustedRouter management key.

Either provider can be used alone, and you can disconnect one in Settings at any time.

Why don't I see charts with my keys?

Charts require the management key. Also check the period — recent usage may be empty while older months have data; use a Custom range to reach further back.

Can I top up my OpenRouter credits in the app?

The app opens the official OpenRouter credits page for you — the actual payment is handled by OpenRouter itself.

Is my API key safe?

Yes. Keys live in the iOS Keychain, never in app preferences or on a server, and each one is only ever sent to that provider's own API over HTTPS. A PIN is stored as a salted SHA-256 hash, never in plain text.

What happens to my data if I delete the app?

Everything is on-device: Keychain keys and UserDefaults preferences go with the app — or immediately, via “Remove all data” in Settings.

Does the app work on iPad?

Yes — it's universal. Models, Settings and Help use sidebar split views with size-adaptive typography on iPadOS 26+.

Why is my "this month" different from the website?

Because "this month" meant three different things. Since 0.1.83 the figures match openrouter.ai: the balance line uses the account-wide calendar month, the chart period is labelled “7 days” / “30 days”, and Settings → Numbers lists every raw figure with its scope — account-wide or this key only.
